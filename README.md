# TechHeads 2026 — Glaze talk

Materials for the 15-minute talk, TechHeads 2026, Kalmar Castle, 1 October 2026.

## One-shot: download and generate everything

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install pandas matplotlib openpyxl requests certifi
python generate_all.py
```

`generate_all.py` fetches every obtainable dataset and builds every figure into
`figures/`. Steps whose data can't be fetched automatically are skipped with a
message (only Ecobee needs a manual download — see below). Nothing here is
destructive; re-running skips datasets already present.

## Scripts

Fetchers (each writes into its own `data*/` folder, all git-ignored):

- `get_data.py` — XAI4HEAT SCADA CSV (Niš, Serbia). `python get_data.py [L4|L8|…]`
- `get_data_se.py` — Ei "levererad värme per prisområde" (Swedish grid sizes),
  resolved via the dataportal.se metadata API.
- `get_data_dk.py` — Danish 3,021 smart-heat-meter dataset (~3.3 GB, Zenodo).
- `get_data_ecobee.py` — Ecobee indoor-temperature dataset. **Manual**: behind a
  data-use agreement, so download by hand and drop the archive in `data_ecobee/`;
  the script then extracts and checks it. It prints the exact steps if the file
  is missing.

Plots (each writes PNGs into `figures/`, git-ignored):

- `plots.py` — XAI4HEAT: winter-week real-time plot + heat-vs-temp scatter w/ fit.
- `plots_se.py` — Swedish grid-size distribution, built from the Ei workbook
  (falls back to last-known published counts if the file can't be parsed).
- `plots_variance.py` — Danish: one-vs-many chaos plot + variance-vs-N curve.
- `plots_ecobee.py` — Ecobee: indoor-temp one-vs-many + variance-vs-N (Celsius).
- `plots_domain.py` — the "what makes DH hard" schematic (no data needed).

## The deck

`Glaze_TechHeads_2026_draft.pptx` is authored (built from the uploaded template,
not generated from code), so it **is** versioned in git — unlike the data and
figures, which are ignored and regenerated by the scripts above. If you don't
see the latest .pptx in this folder, download it from the chat and drop it here.

## Figures used in the deck

- `fig_problem_domain.png` — anchor schematic: slow plant, constrained network,
  many chaotic consumers, one critical worst-off one.
- `fig_realtime_jan.png` — one building, one sensor, a winter week.
- `fig_heat_vs_outdoor_temp.png` — demand vs outdoor temp, with fit line.
- `fig_one_vs_many.png` — one building is chaos; the grid is calm.
- `fig_variance_vs_n.png` — bigger grids are smoother, up to a floor.
- `fig_grid_sizes.png` — most Swedish DH grids are small.

All use the Glaze palette (red D91F22 / near-black 1E1C1D / grey).

## Data provenance / caveats

- XAI4HEAT is Serbian, used as a universal DH example, not Glaze/RACE data.
- Danish smart-meter set is Aalborg residential — good domain match.
- Ecobee is US single-family thermostats — a general "indoor temp is chaotic
  per home, orderly in aggregate" illustration, not district heating.
- Swedish grid sizes: Ei open data ("levererad värme per prisområde"). There are
  ~500 DH systems in Sweden; the distribution shows ~350 networks with size data,
  most delivering ≤ 30 GWh/year.
